# ⚖️ المستشار القانوني — Full Speed

برنامج ويب مجاني بالكامل لقسم الموارد البشرية والشؤون القانونية والمالية: اسأل أي سؤال أو اكتب أي حالة، والبرنامج يجاوب من نصوص القوانين واللوائح نفسها، مع **رقم المادة، والنص، والشرح، والتقاطع مع القوانين الأخرى، وأمثلة عملية**.

يعمل على **Google Sheets + Apps Script** (بدون سيرفر)، ويفتح من الموبايل والكمبيوتر، ويتثبت على الموبايل كتطبيق من **GitHub Pages**.

## المميزات
- **تصميم Full Speed:** نفس هوية موقع الشركة (الأخضر، شبكة المربعات التفاعلية)، وضع **فاتح** أساسي و**غامق** بزرار، وحركة ناعمة في كل الصفحات، وبياخد عرض الشاشة كله على الكمبيوتر والموبايل.
- **الرئيسية:** إحصائيات، أزرار سريعة، آخر أسئلتك، و"إيه الجديد" في القوانين.
- **اسأل المستشار:** إجابة بأربعة أقسام (النص والمادة · التفسير · التقاطع مع القوانين الأخرى · مثال عملي)، والبرنامج **يتحقق آلياً** أن كل نص مقتبس موجود فعلاً في المادة.
- **مساعد الجزاءات:** يحدد الجزاء حسب رقم المخالفة وعدد التكرار، مع ضوابط التحقيق والخصم من قانون العمل.
- **الحاسبات:** الأجر الإضافي، الخصم من الأجر وحدوده، اشتراكات التأمينات، ضريبة المرتبات.
- **المستندات:** إخطار تحقيق، محضر تحقيق، قرار جزاء، إنذار كتابي (Google Docs + PDF) في Drive.
- **تعديل القوانين من البرنامج** (مدير النظام): إضافة قانون أو لائحة جديدة، وإضافة أو تعديل أو حذف أي مادة **بالكتابة**، أو **لصق نص كامل** يتقسم تلقائياً لمواد، أو **صورة / PDF** يقرأها الذكاء الاصطناعي، مع مراجعة قبل الحفظ.
- **Gemini بمفتاحين:** مجاني ومدفوع معاً — المجاني أولاً، ولو خلصت حصته ينتقل تلقائياً للمدفوع، ولو مفيش الاتنين يعرض أقرب المواد (وضع البحث).
- **حماية البيانات الشخصية:** يحذف الأرقام القومية والتليفونات والإيميلات وأرقام الحسابات قبل الإرسال، وينبّه لو اتكتب اسم موظف.
- **محادثة مع لوحة "المواد المرتبطة"** بتعرض نص كل مادة اعتمدت عليها الإجابة، و**السؤال بالصوت** 🎙️.
- **نسخ الإجابة، مشاركتها على واتساب، حفظها PDF**، وزرار **"اعمل قرار الجزاء"** من الإجابة مباشرة.
- **المفضلة ⭐** للمواد اللي بترجع لها كتير، و**بحث سريع Ctrl+K** في كل المواد والصفحات.
- **مساعد جزاءات بخطوات:** المخالفة، بعدها التكرار والمواعيد، وبعدها الجزاء والإجراءات.
- **الدخول بالإيميل** + **"نسيت كلمة المرور"** (كود على الإيميل) + **الدخول بحساب Google** (اختياري).
- **5 حسابات** ينشئها مدير النظام بالإيميل.

## محتويات المستودع
| المسار | ما هو |
|---|---|
| `apps-script/Code.gs` | كود السيرفر كله (يُلصق في Apps Script) |
| `apps-script/Index.html` | الواجهة كلها (يُلصق في ملف `Index`) |
| `docs/` | التطبيق المستقل على GitHub Pages (PWA يتثبت على الموبايل) |
| `modules/` | المصدر المقسّم (للمطوّر) — يُبنى منه الملفان بالأمر `python build.py` |
| `tools/` | بيئة محاكاة لخدمات Apps Script واختبارات الخادم والواجهة |

> ملف البيانات `FullSpeed_Legal_Data.json` والملفات الأصلية PDF **غير موجودة في المستودع عمداً** (لائحة الجزاءات نسخة "غير قابلة للتداول"). ملف البيانات يُرفع مرة واحدة من شاشة الإعداد الأول، والملفات الأصلية على Google Drive.

## التثبيت
### 1. الكود (ملفان)
1. افتح الشيت ← **Extensions ← Apps Script**.
2. في `Code.gs`: امسح المحتوى والصق `apps-script/Code.gs`.
3. **+ ← HTML** باسم `Index` بالضبط، والصق `apps-script/Index.html`.
4. 💾 حفظ.

### 2. النشر
**Deploy ← New deployment ← Web app** — Execute as: **Me** — Who has access: **Anyone** ← انسخ رابط `/exec`.

> "Anyone" تعني أن أي حد معاه الرابط يشوف **صفحة الدخول بس**؛ كل البيانات محمية بالإيميل وكلمة المرور.

### 3. الإعداد الأول (مرة واحدة)
شغّل الدالة `createSetupCode` من المحرر ← خد الكود من Execution log ← افتح الرابط ← اكتب الكود واختر ملف البيانات وأنشئ حساب المدير.

### 4. صلاحية الإيميلات (مرة واحدة بعد أي تحديث بيضيف صلاحيات)
من المحرر اختار الدالة **authorizeEmail** ← **▶ Run** ← وافق على الصلاحيات. دي بتسمح للبرنامج يبعت كود "نسيت كلمة المرور" من إيميلك (حد Google المجاني 100 إيميل في اليوم).

### 5. الدخول بحساب Google (اختياري)
1. `console.cloud.google.com` ← **APIs & Services ← Credentials ← Create credentials ← OAuth client ID ← Web application**.
2. في **Authorized JavaScript origins** ضيف رابط GitHub Pages: `https://<اسم-المستخدم>.github.io`.
3. انسخ الـ **Client ID** والصقه في **الإدارة ← الدخول بحساب Google**.
> الزرار بيشتغل على رابط GitHub Pages. الإيميلات المسجلة في البرنامج بس هي اللي تقدر تدخل.

### 6. مفاتيح Gemini
من **الإدارة ← الذكاء الاصطناعي**:
- **المفتاح المجاني:** من `aistudio.google.com` ← Get API key (مشروع بدون فوترة).
- **المفتاح المدفوع (اختياري):** من مشروع مفعّل عليه Billing — أسئلته لا تستخدمها Google لتحسين خدماتها.
- **طريقة الاستخدام:** المجاني أولاً ثم المدفوع (موصى به)، أو المدفوع فقط، أو المجاني فقط.

المفاتيح تُحفظ في **Script Properties** فقط — **لا تكتب أي مفتاح في الكود أو في المستودع.**

### 7. التطبيق على الموبايل (GitHub Pages)
1. في `docs/config.js` حط رابط `/exec`:
   ```js
   window.FS_API_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```
2. في GitHub: **Settings ← Pages ← Deploy from a branch ← `main` / `docs`**.
3. افتح `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/` من الموبايل ← **Add to Home Screen**.

## تحديث الكود
1. عدّل في `modules/` ثم:
   ```bash
   python build.py
   ```
2. الصق `apps-script/Code.gs` و `apps-script/Index.html` في المحرر.
3. **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** (الرابط لا يتغير).
4. لو عدّلت `docs/`: غيّر `VERSION` في `docs/sw.js` عشان الموبايلات تاخد التحديث.

```bash

```
```bash
node tools/harness.js data/FullSpeed_Legal_Data.json 8090
```
الأمر الأخير يشغّل البرنامج محلياً على `http://localhost:8090` (نسخة Apps Script) و `http://localhost:8090/docs/` (نسخة GitHub Pages).

## الخصوصية
- الخطة المجانية من Gemini قد تستخدم الأسئلة لتحسين خدمات Google؛ لذلك البرنامج يحذف البيانات الشخصية تلقائياً قبل الإرسال وينبّه المستخدم.
- للخصوصية الكاملة استخدم المفتاح المدفوع مع "المدفوع فقط".
- البرنامج أداة مساعدة داخلية ولا يغني عن الاستشارة القانونية المتخصصة في الحالات محل النزاع.
